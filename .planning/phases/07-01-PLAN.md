    - `NotFoundError` in `src/errors/NotFoundError.js` defaulting to statusCode=404 and code='NOT_FOUND'.
    - `ValidationError` in `src/errors/ValidationError.js` defaulting to statusCode=400 and code='VALIDATION_ERROR' with details array.
    - `DatabaseError` in `src/errors/DatabaseError.js` wrapping PostgreSQL driver errors.

    Create the centralized Express error middleware in `src/middleware/errorHandler.js` per D-06 and D-07. Inspect `err.code` for standard ANSI SQLSTATE codes:
    - '23505' (unique_violation) -> HTTP 409 Conflict with message 'A record with this identifier or unique natural key already exists.'
    - '23503' (foreign_key_violation) -> HTTP 400 Bad Request with message 'Referenced entity does not exist in the database.' per NFR-02.
    - '23514' (check_violation) -> HTTP 422 Unprocessable Entity with message 'Input violates domain business rules (e.g. date ordering or score bounds).'
    - '22P02' (invalid_text_representation) -> HTTP 400 Bad Request with message 'Invalid parameter format (e.g. non-numeric ID supplied).'
    - '23502' (not_null_violation) -> HTTP 400 Bad Request with message detailing missing mandatory column.
    - 'ECONNREFUSED', '57P01', '08006' -> HTTP 503 Service Unavailable with message 'Database service is currently unreachable.'

    Format all responses into the JSend envelope: status ('fail' for 4xx, 'error' for 5xx), message, code, and optional errors/detail. Register `errorHandler` as the final middleware in `src/app.js`.

    Create unit tests in `tests/unit/errorHandler.test.js` validating translation of synthetic mock PostgreSQL errors into correct HTTP status codes and JSend envelopes.
