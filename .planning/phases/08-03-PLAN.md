  <name>Task 1: Authentication & RBAC Middleware Engine</name>
  <files>
    backend/src/middleware/auth.js,
    backend/tests/integration/rbacCandidate.test.js
  </files>
  <action>
    Create `src/middleware/auth.js` implementing authorization guards per AUTH-07:
    - `authenticateToken(req, res, next)`:
      - Reads JWT token from `req.cookies['sb_auth_token']` or fallback `Authorization: Bearer <token>` header.
      - If missing, forwards AppError with HTTP 401 Unauthorized (`code: 'AUTHENTICATION_REQUIRED'`).
      - Verifies token via `authService.verifyJwt(token)`.
      - If expired, forwards AppError with HTTP 401 Unauthorized (`code: 'TOKEN_EXPIRED'`).
      - If invalid, forwards AppError with HTTP 401 Unauthorized (`code: 'TOKEN_INVALID'`).
      - Attaches decoded payload to `req.user = { userId: decoded.sub, email: decoded.email, role: decoded.role }`.
      - Calls `next()`.
    - `requireRole(...allowedRoles)`:
      - Returns middleware checking if `allowedRoles.includes(req.user?.role)`.
      - If user does not possess required role, forwards AppError with HTTP 403 Forbidden (`code: 'FORBIDDEN_ROLE'`, `message: 'Access restricted to authorized roles.'`).
      - Calls `next()`.
    - `requireOwnershipOrCounselor(paramName = 'id')`:
      - Checks if `req.user.role === 'counselor' || req.user.role === 'admin'`.
      - If candidate, compares `req.user.userId === parseInt(req.params[paramName], 10)`.
      - If candidate attempts to access another user's ID, forwards AppError with HTTP 403 Forbidden (`code: 'FORBIDDEN_RESOURCE_ACCESS'`, `message: 'Candidates are authorized to access only their own resources.'`).
      - Calls `next()`.

    Author integration test `tests/integration/rbacCandidate.test.js` validating:
    1. Request without auth cookie receives HTTP 401.
    2. Request with expired or tampered token receives HTTP 401.
    3. Valid candidate token attaches user and passes through.
  </action>
  <verify>
    <automated>node --test backend/tests/integration/rbacCandidate.test.js</automated>
  </verify>
  <done>
    Auth middleware accurately validates JWT tokens from cookies, enforces role constraints, and checks resource ownership.
  </done>
</task>
