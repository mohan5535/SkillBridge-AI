    - Outputs single-use activation link.
    - Closes pool cleanly.

    - `SEC-02 (Expired Activation Token)`: Token with `activation_token_expires_at` set in past is rejected with HTTP 400.
    - `SEC-03 (Token Reuse Prevention)`: Token activated once is immediately cleared (hash = NULL); second activation attempt fails with HTTP 400.

    - `SEC-05 (Public Role Escalation)`: Registering with `{ role: 'counselor' }` creates row with `role = 'candidate'`.
    - `SEC-06 (CSRF Missing Header)`: Authenticated mutation without `X-CSRF-Token` header fails with HTTP 403 Forbidden.
    - `SEC-07 (CSRF Forgery / Tampering)`: Authenticated mutation with tampered `X-CSRF-Token` fails with HTTP 403.
    - `SEC-08 (Cross-Candidate Isolation)`: Candidate 1 authenticated cookie attempting GET /api/users/2 or PUT /api/users/2 receives HTTP 403 Forbidden.

    - `SEC-11 (Brute-Force Rate Limiting)`: 6 rapid failed logins trigger HTTP 429 Too Many Requests.
    - `SEC-12 (Zero Data Loss Guarantee)`: Pre-test vs post-test count across all 22 tables verifies exactly 174 records preserved.
